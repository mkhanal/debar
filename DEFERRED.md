# Deferred

Initiatives outside the first release. Each is taken up as its own piece of work when someone needs it. One item per `##`.

## An in-process library interface

A library other software links and calls directly, in addition to the daemon and the commands.

## Language bindings

Wrappers for other languages over the library interface.

## Mail filter

Scanning mail as it passes through a mail server.

## On-access scanning

Scanning files as they are opened or written.

## Windows and macOS

The first release is Linux only. Techniques tied to Linux stay inside the platform layer so other systems are not ruled out.
